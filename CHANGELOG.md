# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-09-08

### Added

- Split-panel CV editor with live HTML preview and ATS-friendly single-column template
- Multi-profile support backed by SQLite
- Bilingual CV content (Turkish / English) with localized section labels
- Application UI language (Turkish / English) with first-run setup
- PDF export via headless Chrome (`chromedp`)
- Google Translate and OpenAI translation providers
- AI assistant for conversational CV creation and editing (OpenAI)
- Local PDF OCR for scanned resumes (Tesseract + embedded text extraction)
- Profile photo upload
- JSON backup and restore (single profile and full export/import)
- Embedded demo profile: **Full Stack Developer** with TR + EN content on first run
- Docker and Docker Compose support
- Dark mode
